## **1️⃣ Network Interface Commands**

### **🔹 `ifconfig` - Show Network Interfaces**
```bash
# Show all network interfaces
ifconfig

# Show specific interface
ifconfig eth0

# Expected Output:
eth0: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 1500
        inet 192.168.174.128  netmask 255.255.255.0  broadcast 192.168.174.255
        inet6 fe80::20c:29ff:feb6:8e17  prefixlen 64  scopeid 0x20<link>
        ether 00:0c:29:b6:8e:17  txqueuelen 1000  (Ethernet)
```

### **🔹 `ip a` - Modern Interface Info**
```bash
# Show all interfaces (newer command)
ip a

# Show specific interface
ip addr show eth0
```

### **🔹 Interface Types Explained**
```
eth0   = 🔌 Wired Ethernet (LAN cable)
wlan0  = 📶 Wireless WiFi adapter
lo     = 🔄 Loopback (localhost 127.0.0.1)
```

## **2️⃣ IP & Routing Commands**

### **🔹 `ip route` - Show Routing Table**
```bash
# Show routing table
ip route

# Example Output:
default via 192.168.174.2 dev eth0 proto dhcp src 192.168.174.128 metric 100 
192.168.174.0/24 dev eth0 proto kernel scope link src 192.168.174.128 metric 100
```

### **🔹 Gateway & Public IP Discovery**
```bash
# Find your public IP
curl ifconfig.me
# Output: 119.148.19.193

# Find gateway/router IP
ip route | grep default
# Output: default via 192.168.174.2 dev eth0
```

### **🔹 `traceroute` - Trace Route to Destination**
```bash
# Trace path to Google
traceroute google.com

# Expected Output:
traceroute to google.com (142.250.196.78), 30 hops max, 60 byte packets
 1  _gateway (192.168.3.1)  1.024 ms  0.894 ms  0.834 ms
 2  119.148.19.193 (119.148.19.193)  85.838 ms  1.091 ms  1.126 ms
 3  172.16.55.217 (172.16.55.217)  42.841 ms  43.121 ms  43.338 ms
```

## **3️⃣ DNS Resolution Commands**

### **🔹 `nslookup` - DNS Query**
```bash
# Basic DNS lookup
nslookup google.com

# Example Output:
Server:		192.168.174.2
Address:	192.168.174.2#53

Non-authoritative answer:
Name:	google.com
Address: 142.250.195.78
```

### **🔹 `dig` - Advanced DNS Query**
```bash
# Detailed DNS info
dig google.com

# Trace full DNS resolution
dig google.com +trace
```

### **🔹 DNS Configuration Files**
```bash
# View DNS servers
cat /etc/resolv.conf

# Output:
# Generated by NetworkManager
search localdomain
nameserver 192.168.174.2
```

## **4️⃣ Complete DNS Resolution Journey**

```
┌─────────────────────────────────────────────────────────────────────┐
│                    DNS Resolution Process                           │
└─────────────────────────────────────────────────────────────────────┘

 User's Computer (192.168.1.100)
     │
     │── [google.com?] ──► Local Resolver (ISP's DNS: 192.168.174.2)
     │                        │
     │                        │── [google.com?] ──► Root DNS Server (.)
     │                        │                       │
     │                        │                       │── [.com TLD?] ──► TLD Server (.com)
     │                        │                       │                       │
     │                        │                       │                       │── [NS Records] ──► NS1.google.com
     │                        │                       │                       │                   NS2.google.com
     │                        │                       │                       │
     │                        │                       │◄── [Referral: NS1, NS2] ──│
     │                        │
     │── [google.com?] ──► NS1.google.com (Authoritative Name Server)
     │                        │
     │                        │── [Checks A Record for google.com]
     │                        │                          │
     │                        │                          │── [Finds IP] ──► 142.250.190.46
     │                        │
     │◄── [142.250.190.46] ───│
     │
 Browser connects to 142.250.190.46 ──► google.com loads! 🎉
```

## **5️⃣ Port & Connection Commands**

### **🔹 `netstat` - Show Network Connections**
```bash
# Show all connections with programs
netstat -antp

# Flags explained:
# -a = all connections
# -n = numerical addresses (no DNS resolution)
# -t = TCP connections
# -p = show process/program names

# Example Output:
Proto Recv-Q Send-Q Local Address           Foreign Address         State       PID/Program name    
tcp        0      0 192.168.174.128:52384   142.250.182.142:443     ESTABLISHED 2944/firefox-esr
```

### **🔹 `ss` - Modern Socket Statistics**
```bash
# Modern alternative to netstat
ss -tulnp

# Show listening ports only
ss -tln
```

### **🔹 Common Port Numbers**
```
Port 20  = FTP Data Transfer
Port 21  = FTP Command Control
Port 22  = SSH (Secure Shell)
Port 23  = Telnet
Port 25  = SMTP (Email)
Port 53  = DNS
Port 80  = HTTP (Web)
Port 110 = POP3 (Email)
Port 143 = IMAP (Email)
Port 443 = HTTPS (Secure Web)
Port 993 = IMAPS (Secure IMAP)
Port 995 = POP3S (Secure POP3)
```

## **6️⃣ Network Testing Commands**

### **🔹 `ping` - Test Connectivity**
```bash
# Basic ping
ping google.com

# Ping with count
ping -c 4 google.com

# Ping local gateway
ping 192.168.1.1
```

### **🔹 `curl` - Test HTTP/HTTPS**
```bash
# Get HTTP headers
curl -I google.com

# Get public IP
curl ifconfig.me

# Test specific port
curl -v telnet://192.168.1.1:80
```

### **🔹 `nmap` - Port Scanning**
```bash
# Scan single host
nmap google.com

# Scan specific ports
nmap -p 80,443 google.com

# Scan local network
nmap -sP 192.168.1.0/24
```

## **8️⃣ Network Concepts Explained**

### **🔹 NAT (Network Address Translation)**
```
Internal Network          Router (NAT)           External Network
─────────────────         ─────────────         ─────────────────
192.168.1.100:5000  ──►   203.0.113.50:40001  ──►  142.250.190.46:443
192.168.1.101:6000  ──►   203.0.113.50:40002  ──►  142.250.190.46:443
192.168.1.102:7000  ──►   203.0.113.50:40003  ──►  142.250.190.46:443

Multiple private IPs share ONE public IP through port mapping
```

### **🔹 Subnet Explanation**
```
Subnet: 192.168.1.0/24
───────────────────────
Network:    192.168.1.0      (Network ID)
Subnet Mask: 255.255.255.0   (24 bits for network)
Gateway:    192.168.1.1      (Router IP)
Range:      192.168.1.2-254  (Available for devices)
Broadcast:  192.168.1.255    (Broadcast address)

/24 = 255.255.255.0 (24 ones in binary)
/16 = 255.255.0.0   (16 ones in binary)
/8  = 255.0.0.0     (8 ones in binary)
```

### **🔹 Router Core Functions**
```
┌─────────────────────────────────────────────────────────────┐
│                    Router Functions                         │
├─────────────────────────────────────────────────────────────┤
│ 1. NAT        │ Translates private ↔ public IPs           │
│ 2. DHCP       │ Assigns IP addresses automatically        │
│ 3. Firewall   │ Filters traffic based on rules           │
│ 4. DMZ        │ Isolated network zone for servers        │
│ 5. Routing    │ Directs packets to correct destination    │
└─────────────────────────────────────────────────────────────┘
```

## **9️⃣ Advanced Network Analysis**

### **🔹 `tcpdump` - Packet Capture**
```bash
# Capture packets on interface
tcpdump -i eth0

# Capture HTTP traffic only
tcpdump -i eth0 port 80

# Capture and save to file
tcpdump -i eth0 -w capture.pcap
```

### **🔹 `iperf3` - Network Speed Test**
```bash
# Server mode
iperf3 -s

# Client mode (test to server)
iperf3 -c server_ip
```

### **🔹 `arp` - MAC Address Resolution**
```bash
# Show ARP table (IP to MAC mapping)
arp -a

# Example Output:
_gateway (192.168.1.1) at 00:1a:2b:3c:4d:5e [ether] on eth0
```

## **🔟 Troubleshooting Workflow**

### **🔹 Network Troubleshooting Steps**
```
1. Check Physical Connection
   ┌─────────────────────────────────────┐
   │ ip link show                        │  ← Check if interface is UP
   │ ethtool eth0                        │  ← Check cable/link status
   └─────────────────────────────────────┘

2. Check IP Configuration
   ┌─────────────────────────────────────┐
   │ ip addr show                        │  ← Verify IP address
   │ ip route show                       │  ← Check routing table
   └─────────────────────────────────────┘

3. Test Local Connectivity
   ┌─────────────────────────────────────┐
   │ ping 127.0.0.1                     │  ← Test loopback
   │ ping 192.168.1.1                   │  ← Test gateway
   └─────────────────────────────────────┘

4. Test DNS Resolution
   ┌─────────────────────────────────────┐
   │ ping 8.8.8.8                       │  ← Test external IP
   │ nslookup google.com                 │  ← Test DNS resolution
   └─────────────────────────────────────┘

5. Test Application Layer
   ┌─────────────────────────────────────┐
   │ curl -I google.com                  │  ← Test HTTP
   │ netstat -antp                       │  ← Check open connections
   └─────────────────────────────────────┘
```

## **🚀 Quick Reference Commands**

```bash
# Essential Network Info
ip a                          # Show all interfaces
ip route                      # Show routing table
curl ifconfig.me             # Show public IP
cat /etc/resolv.conf          # Show DNS servers

# Connectivity Tests
ping google.com               # Basic connectivity
traceroute google.com         # Route tracing
nslookup google.com          # DNS resolution
curl -I google.com           # HTTP headers

# Network Monitoring
netstat -antp                # Active connections
ss -tulnp                    # Modern connection stats
tcpdump -i eth0              # Packet capture
nmap -sP 192.168.1.0/24     # Network scan

# Advanced Troubleshooting
dig google.com +trace        # Full DNS trace
iperf3 -c server_ip         # Speed test
arp -a                      # MAC address table
ethtool eth0                # Interface diagnostics
```

---

**💡 Pro Tips:**
- Always check `ip route` for gateway issues
- Use `curl ifconfig.me` to verify public IP
- Combine `ping` + `traceroute` for connectivity debugging
- `netstat -antp` shows which programs use which ports
- DNS issues? Check `/etc/resolv.conf` first!

# 🔑 Ports & Protocols

👉 **Ports** are just numbers used to identify services.
👉 A port can be **TCP** or **UDP** (sometimes both).

---

### ✅ Common TCP Ports

Reliable (connection-based, error-checked).

```
HTTP      : 80 (TCP)  
HTTPS     : 443 (TCP)  
SSH       : 22 (TCP)  
FTP       : 21 (TCP)  
SMTP      : 25 (TCP)  
IMAP      : 143 (TCP)  
MySQL     : 3306 (TCP)
```

---

### ✅ Common UDP Ports

Fast (connectionless, no delivery guarantee).

```
DNS Query : 53 (UDP)  
DHCP      : 67/68 (UDP)  
SNMP      : 161 (UDP)  
NTP       : 123 (UDP)  
VoIP/Calls: 5060 (UDP)  
Streaming : 5004/5005 (UDP)
```

---

### ⚖️ Both TCP & UDP (depends on use)

```
DNS      : 53 (UDP for queries, TCP for zone transfers)  
HTTPS/QUIC: 443 (UDP in QUIC, TCP normally)  
```

# 🏛️ OSI Model vs Real Life

OSI has **7 layers**, TCP/IP has **4 layers** (used in real world).

---

### 📚 OSI Layers (theory)

```
7. Application  → HTTP, DNS, SSH  
6. Presentation → SSL/TLS, JPEG, MP3  
5. Session      → NetBIOS, RPC  
4. Transport    → TCP, UDP  
3. Network      → IP, ICMP  
2. Data Link    → Ethernet, Wi-Fi (MAC)  
1. Physical     → Cable, Radio waves
```

---

### 🌍 TCP/IP Layers (real-life stack)

```
4. Application  → HTTP, DNS, SSH, FTP  
3. Transport    → TCP, UDP  
2. Internet     → IP, ICMP, ARP  
1. Network Access → Ethernet, Wi-Fi, Fiber
```

---

### 📡 Real-Life Packet Flow

```
[App Layer]   HTTP Request (GET /index.html)  
[Transport]   TCP segment (port 80)  
[Internet]    IP packet (src/dst IP)  
[Link]        Ethernet frame (MAC src/dst)  
[Physical]    0/1 bits over cable/wifi
```

---

⚡Quick Reminder:

* **TCP → Reliable** (used in browsing, email, SSH, DB)
* **UDP → Fast** (used in DNS, calls, gaming, streaming)
